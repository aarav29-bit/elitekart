 EliteKart

EliteKart is a demo multi-category e-commerce platform built with HTML, CSS, and JavaScript.  
It focuses on promoting Indian local handicrafts while also including other product categories.  

The platform features user login, seller login, cart system, weather-aware delivery scheduling, and an AI chatbot to assist users.


 Live Demo
 https://aarav29-bit.github.io/elitekart/

  


 Features

-  Dark & Light mode support  
-  User & Seller login pages  
-  Cart functionality  
-  Product categories: Handicrafts, Appliances, Laptops & Accessories, Fashion, Beauty, Home Décor  
-  Weather report page (helps users schedule deliveries)  
-  AI chatbot for customer support  
-  Responsive design (desktop & mobile friendly)
